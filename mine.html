This list lives only in this browser: nobody else sees it, nothing is tracked, and it empties the moment this browser's storage is cleared. This page adds no urgency and asks nothing of you; it only shows what you already marked, in the order you marked it.

Technical wording

Every card id found in this browser's pk-stars localStorage entry, in the order it was starred, matched against the modeled universe and rendered with each card's current market price, its predicted 90-day market-relative move and 80 percent band, its flag, and its Europe versus US price ratio where one is measured. Nothing here is sent to a server or compared across readers.

Read this before relying on this list

This page reads only the star list already sitting in this browser's own storage. It keeps no server-side record of what you starred, tracks no visits, and never compares one reader against another. The list lives only in this browser and empties the moment its storage is cleared, and a star set on one browser or device never appears on another. The order shown is simply the order you starred cards in; there is no ranking and no suggestion to act, here or anywhere else on this page.
