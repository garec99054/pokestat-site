Data sources and coverage

Data sources

  • TCGplayer USD prices via the tcgcsv.com daily archive (market model, backtest).
  • TCGplayer USD prices via a live TCGdex snapshot (second independent USD source, shown as the outlook "2nd source" cross-check column; display-only, never a model input). Its gap from the model market price blends true source disagreement with genuine price drift, since the model price is frozen at its snapshot date while this one is live.
  • Cardmarket EU prices via TCGdex (display-only reference columns).
  • Wikimedia pageviews for the character-appeal feature (as-of-T backfill).
  • Card artwork lazy-loaded from the two catalog hosts the store actually carries, images.pokemontcg.io and images.scrydex.com (display only, URLs never image bytes). The older catalog is on the first host; the most recently released sets appear only on the second, so a single-host policy would silently blank their thumbnails.

Model tiering, sourcing, and page doctrine

Model tiering

Where model-generated content appears, capability is tiered Fable > Opus > Sonnet/Haiku: Fable for the deepest reasoning and adversarial verification, Opus for framework and analysis work, and Sonnet/Haiku for high-frequency worker tasks (for example the artwork rater fleet). The forward model selection itself is mechanical and model-agnostic.

Trusted reseller sources & ToS discipline

Prices come only from official or free archival APIs (tcgcsv.com for the TCGplayer model series, and TCGdex for both the Cardmarket EU columns and the second TCGplayer USD cross- check). eBay and PriceCharting remain excluded. Marketplace links are user navigation, not scraping, and thumbnails are lazy-loaded read-only assets.

Cardmarket product URLs return HTTP 403 to automated agents (Cloudflare bot-blocking on a non-browser user agent) but resolve normally for human navigation; the links are for a person to click, not for the pipeline to fetch.

Page doctrine (amended for this build)

Every page is self-contained (inline CSS/JS/SVG) with two amended exceptions: (a) outbound links to TCGplayer and Cardmarket product pages, and (b) lazy-loaded external card artwork from the two catalog hosts in cards.image_url, images.pokemontcg.io and images.scrydex.com, each with loading="lazy" and an onerror fallback to a styled placeholder. The second host is not optional: the most recently released sets are catalogued only there, so pinning one host would render their cards as placeholders while every check still passed. Only the URL travels, never the image. Everything else stays inline, and every page still renders fully offline minus the artwork.
